# Accessibility standard (WCAG 2.2 AA is the floor)

- Contrast: text 4.5:1 (large 3:1), UI boundaries/icons/focus 3:1. Tokens are pre-validated; custom colors are not allowed anyway.
- Keyboard: everything operable by keyboard, logical tab order, no traps, WAI-ARIA APG patterns (use Radix/React Aria; do not hand-roll dialog, menu, tabs, combobox, select).
- Focus: always visible (`:focus-visible` ring from tokens). Never `outline: none` without a replacement. Move focus into dialogs and back on close.
- Targets: >= 24x24 CSS px (WCAG 2.2 2.5.8); 44x44 on touch.
- Semantics: real `<button>`/`<a>`/`<label>`/headings in order; landmarks (`header nav main footer`), exactly one `<main>` (the root layout owns it, pages never add another); one `h1`. Skip link on content-heavy pages.
- Images/icons: meaningful `alt`; decorative `alt=""` / `aria-hidden`. Icon-only buttons need `aria-label`.
- Never color alone for state: pair with icon + text. Errors: text + icon + `role="alert"` or `aria-live`.
- Motion: respect `prefers-reduced-motion` (tokens do globally); no autoplay >5s without pause; no flashing.
- Forms: label, `autocomplete`, `inputmode`, error association, don't clear input on failure; don't block paste.
- Zoom/reflow: works at 200% zoom and 320px width, no horizontal scroll, no `user-scalable=no`. Don't hide scrollbars.
- Live regions for async results (`aria-live="polite"` for loaded counts/toasts).
- Mobile: dynamic type respected, `accessibilityLabel`/`accessibilityRole`/`accessibilityState` on every Pressable.
- Test: eslint-plugin-jsx-a11y, `@axe-core/playwright` in e2e on main pages, manual keyboard pass before release.
