# Guide

| Skill | Command | Use it to |
|---|---|---|
| `init` | `/house-style:init` | [Set up a project](init.md): accent, icon, tokens, templates |
| `audit` | `/house-style:audit` | [Measure](audit.md) how far a repo is from the standard |
| `release` | `/house-style:release` | [Cut a version](release.md) from Conventional Commits |
| `house-style` | automatic | Applies the standard when you build UI, backend, docs or releases |
